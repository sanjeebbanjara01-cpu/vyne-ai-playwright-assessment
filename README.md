# Vyne AI Playwright Assessment

A Playwright and TypeScript test automation framework created from scratch for the Senior QA Engineer take-home exercise.

## Test targets

- Web UI: SauceDemo
- API: JSONPlaceholder

## Planned coverage

- UI authentication and critical shopping workflows
- API CRUD validation for posts and users
- Reusable page objects, fixtures, test data, and API clients
- HTML reporting and CI execution
- Documentation of AI prompts, technical decisions, and AI-output evaluation

## Getting started

```bash
npm install
npx playwright install
npm test
```
